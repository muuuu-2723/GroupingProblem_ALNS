# 対象プログラム概要

## 1. 概要
本プログラムは、多様なグループ分け問題を対象とした最適化ソルバープログラムである。

利用者がJSONファイルとして定義したグループ分け問題を入力として受け取り、最適解または最適解に近い近似解を探索し、その結果を出力する。

対象とする問題は、ビンパッキング問題、一般化割当問題、施設配置問題など、多くのグループ分け問題である。

## 2. 特徴
本プログラムは、特定のグループ分け問題専用ではなく、JSONで問題構造や評価関数を定義することで、複数種類のグループ分け問題に対応できる。

評価関数はソースコード上で固定されておらず、入力JSONファイルで定義する。

## 3. 使用技術
- 使用言語：C++
- ビルド方法：Makefile
- 実行方式：CLI
- 入力形式：JSON
- 出力形式：コマンドライン表示
- 確認済み環境：Windows、WSL2
- 未確認環境：Linux、macOS

## 4. 入力
入力は、グループ分け問題を定義したJSONファイルである。

現行では、Data配下に以下のJSONファイルが存在する。

- A-n32-k5.json
- template_json.json

## 5. 出力
出力は、基本的にコマンドライン上に表示される。

ただし、result.txt が存在するため、ファイル出力の有無については確認が必要である。

## 6. 探索アルゴリズム
Adaptive Large Neighborhood Searchをもとに、通常の近傍探索も組み合わせて探索を行う。

現行プログラムでは、以下の探索手法を用いる。

- 近傍探索法：3種類
- 破壊法：5種類
- 修復法：7種類

## 7. ファイル構成概要
- Data/：入力JSON、テンプレートJSON
- src/：C++ソースコード本体
- src/Destroy/：破壊法
- src/Search/：探索法・修復法・近傍探索法
- src/Group/：グループを表すクラス
- src/Item/：アイテムを表すクラス
- src/Solution/：解を表すクラス
- src/Input/：JSON入力処理
- src/Weight/：重み・評価関連の処理
- src/MyRandom/：乱数処理
- src/Debug/：デバッグ処理
- src/DrawGraph/：グラフ描画用Pythonスクリプト
- bat/：Windows用補助スクリプト
- shell/：Linux / WSL用補助スクリプト

## 8. リファクタリング対象範囲
以下をリファクタリングおよび確認対象とする。

- src/ 配下のC++ソースコード
- Data/ 配下のJSON
- Makefile
- README.md
- bat/ および shell/ 配下の補助スクリプト
- result.txt
- src/DrawGraph/draw_graph.py

## 9. 現時点での要確認事項
- result.txt がプログラムにより生成される出力ファイルかどうか
- draw_graph.py の利用有無
- Linux環境を正式な対応対象に含めるかどうか
- 3種類の近傍探索法の詳細
- 5種類の破壊法の詳細
- 7種類の修復法の詳細
