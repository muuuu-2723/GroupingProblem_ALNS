# プロジェクト目的・ゴール定義

## プロジェクト目的
本プロジェクトの目的は、卒論で作成した現行プログラムを整理し、可読性・保守性を向上させたうえで、卒論時点で今後の課題としていた機能改善を実施することである。

## 最終ゴール
本プロジェクトの最終ゴールは、以下を満たすソースコードを作成することである。

1. 卒論時に今後の課題としていた焼きなまし法の機能が追加されていること
2. 現行ソースコードのコメントが整備され、処理内容を理解しやすい状態になっていること
3. 現行のJSONインプットについて、構造および入力方法の妥当性が確認されていること
4. JSONインプットに改善余地がある場合は、構造または入力方法が見直されていること
5. 今後の修正・機能追加がしやすい構成になっていること

## 重視する観点
- 焼きなまし法の機能追加
- コメント整備による可読性向上
- JSONインプットの構造・入力方法の見直し
- 既存機能を維持したうえでの改善

## 完了条件
本プロジェクトは、以下を満たした時点で完了とする。

- 焼きなまし法の機能が追加されている
- 現行ソースコードのコメントが整備されている
- 現行JSONインプットの構造・入力方法について見直しが完了している
- JSONインプットを変更しない場合は、変更不要と判断した理由が明文化されている
- 既存機能がリファクタリング後も動作する
- 追加した焼きなまし法の機能が動作する
- リファクタリング後のソースコードについて、主要な設計内容・実行方法が確認できる状態になっている
