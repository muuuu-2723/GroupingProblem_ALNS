## 指摘区分

| 指摘区分 | 内容 |
|---|---|
| 誤字 | 文字の誤り |
| 表記ゆれ | 用語や表現の不統一 |
| 表現修正 | 分かりにくい表現の修正 |
| Markdown修正 | Markdown構文、表、見出し、コードブロックの修正 |
| Mermaid修正 | Mermaid図の構成・表示・見やすさの修正 |
| 不足 | 必要な情報が不足している |

| 要確認 | ユーザー判断が必要 |
| その他 | 上記に該当しない指摘 |

## 修正時の制約

- 指摘票に記載された範囲を優先して修正すること。
- 指摘内容と関係のない大規模な変更は行わないこと。
- 既存仕様を変更する場合は、変更理由を明記すること。
- 不明点がある場合は、推測で修正せず要確認事項として残すこと。
- ソースコードの文字コードはCP932のまま維持すること。
