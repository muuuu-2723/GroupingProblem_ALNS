# Review Tickets

このディレクトリでは、ChatGPTまたは人間レビューで発生した指摘事項を管理する。

## 目的

レビュー指摘内容をファイルとして残し、GitHub Copilot Agent Mode に修正指示として読み込ませることで、修正対応の履歴と根拠を管理する。

## 運用ルール

- レビュー指摘は `docs/reviews/` 配下にMarkdownで作成する。
- 指摘票はSTEP単位で管理する。
- Copilotに修正させる場合は、対象の指摘票ファイルを明示する。
- 指摘番号を付与し、修正後に対応状況を更新する。
- 指摘票には、対象ファイル、指摘内容、期待する修正内容を必ず記載する。
- 指摘票にない追加修正は原則行わない。
- 対応完了後、必要に応じてステータスを `対応済み` に更新する。
